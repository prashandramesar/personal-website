# Dog breed classifier
Source: /dog_classifier

## The dog breed classifier project
This is a hobby project you can try on this site. Upload a photo of a dog, and a computer vision model identifies its breed from 120 different dog breeds.

## How the dog breed model was built
The model is based on a pre-trained MobileNetV2 backbone with custom classification layers on top, fine-tuned for dog breed recognition and converted to a quantized TensorFlow Lite model. It runs on the same service as this website.
