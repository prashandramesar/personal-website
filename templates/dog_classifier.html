About This Project

This dog breed classification system uses a deep convolutional neural network (CNN) trained on thousands of dog images. The model has been fine-tuned to recognize subtle differences between various dog breeds.

The model architecture is based on a pre-trained MobileNetV2 backbone with custom classification layers added on top, fine-tuned for dog breed recognition and converted to a quantized TensorFlow Lite model.

The model runs on the same Render service as this website and can identify 120 different dog breeds.

Technologies Used:

  • TensorFlow / TensorFlow Lite
  • FastAPI
  • Flask
