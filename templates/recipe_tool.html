Recipe Tool

A hobby project: give it a recipe link or a pasted caption, and it returns the ingredients and steps, always in metric and Celsius. I can then check the result, save it and search my collection. The tool itself is private, so this page shows what it does using one of my own recipes.

Example: my masala chai

The amounts below come from the tool's conversion code. Cups are read as US cups, because the recipe doesn't say otherwise.

Steps

  1. 1. Simmer the whole spices and ginger in boiling water for 3-4 minutes.
  2. 2. Next, add the loose black tea and boil for another minute.
  3. 3. Then add your whole milk and bring it back to the boil. Make sure to kill the heat right before the milk boils over. Repeat this step a few times.
  4. 4. Finally, strain the masala chai into two cups and add sugar to taste. Enjoy!

How it works

  1. 1. Get the text. It fetches the link, or takes pasted text, and trims a page down to just the recipe.
  2. 2. Read it with Claude. One call turns messy text, in English or Dutch, into structured ingredients and steps.
  3. 3. Convert it in code. Plain Python does every calculation, with cup weights from USDA FoodData Central.
  4. 4. Check it. I see each conversion next to its original text, with notes on anything uncertain, and can edit it before saving.

Decisions I made

  • The model reads, and code calculates. A language model is good at messy text, but a recipe's arithmetic has to be right every time and easy to test. So the model never calculates a quantity.
  • Show doubt instead of guessing. A cup of flour and a cup of honey weigh very different amounts. If the tool doesn't have a sourced weight for an ingredient, it shows millilitres with a note and doesn't invent grams.
  • Respect the platforms' rules. Instagram, TikTok and YouTube restrict automated collection, and some websites block it. Instead of working around that, the tool asks me to paste the text. YouTube's API was an option, but its rules on storing and deriving data conflict with saving recipes, so I left it out.
  • Keep it private. It sits behind a login, because a public tool that fetches any link invites abuse, and saved recipes are other people's work. That's also why this example is my own recipe.
